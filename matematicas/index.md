# 01 · Matemáticas para visión por computadora

Este módulo construye las herramientas que necesitaremos para entender imágenes, modelos y entrenamiento. Usaremos ejemplos visuales desde el inicio, pero explicaremos cada concepto antes de emplearlo.

## Objetivos del módulo

Al terminar podrás representar una imagen como números, razonar con funciones y coordenadas, operar con vectores y matrices, interpretar una derivada y entender la incertidumbre en un conjunto de datos.

## Secuencia de clases

1. Números, variables y funciones: intensidad y brillo de un píxel.
2. Coordenadas y gráficas: ubicación de un píxel y plano cartesiano.
3. Vectores: colores RGB, magnitud y distancia.
4. Matrices: imágenes en escala de grises y operaciones elementales.
5. Álgebra lineal: productos, transformaciones y cambios de base.
6. Funciones de varias variables, límites y derivadas.
7. Gradientes y regla de la cadena: preparación para entrenar redes.
8. Probabilidad y estadística: datos, ruido e incertidumbre.

La secuencia se ampliará con ejercicios de repaso y laboratorios conforme avance el curso. La clase 1 no requiere álgebra lineal, cálculo ni experiencia en Python.

## Convención de cada clase

Objetivos → intuición → definición → ejemplo a mano → código → ejercicios → respuestas → conexión con visión por computadora.
